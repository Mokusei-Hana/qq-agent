# 自主学梗模块（实验版）

## 状态

该分支新增 `src/meme-learning.js`，实现独立的 `MemeLearningManager`：延迟初始化 SQLite、限定群采集、联网证据注入、模型分析注入、跨域佐证、知识检索、纠错反馈和过期状态维护。

**本提交是独立模块与测试基线，尚未接入 `app.js` 的生产事件流，也未增加管理控制台页面或配置开关。** 因此它不会改变现有机器人行为；不要把它当作已上线功能。

## 边界与数据流

1. 宿主显式启用后才创建数据库；默认关闭时不创建文件、不启动定时器、不观察消息。
2. 只允许配置白名单中的群号进入候选队列；私聊、自身消息、疑似链接/CQ 码内容被忽略。
3. 网络搜索、网页抓取和模型分析均由宿主通过依赖注入提供。模块本身不持有 API Key，不直接执行网页中的指令。
4. 每个词条保留来源 URL、域名、标题、摘录和抓取时间。至少两个不同域名、模型显式标记 verified 且置信度达到阈值才进入 active 状态；否则为 pending，不参与聊天检索。
5. 群聊检索只返回 active 且未过期词条。调用方应把释义当作不可信参考资料，而不是系统指令。
6. 错误反馈会把词条隔离为 pending（提供纠正内容时）或 disabled；过时反馈将其标记 expired。
7. 停用不删除数据。TTL 只改变状态，不自动删除证据。

## SQLite 表

- `meme_candidates`：白名单群内观察到的候选表达及频次。
- `memes`：释义、别名、使用场景、语气、置信度、状态和过期时间。
- `meme_sources`：来源追踪与交叉验证。
- `meme_feedback`：纠错记录。

## 接入生产环境的下一步

- 在 `config-legacy.js` 添加默认关闭的 `memeLearningPilot` 配置；不要复用已经退休的 `slangPilot` 字段。
- 在配置适配层实现独立的启用/毕业状态策略，确保旧配置迁移不会自动启用。
- 在 `app.js` 创建管理器并注入现有 `webSearch`、安全网页抓取和 `chatCompletion` 适配器；OneBot 消息入站时仅把已授权群的普通文本交给 `observeMessage`。
- 在 prompt/tool 层提供只读检索入口；不要把词条直接拼成高优先级系统提示。
- 按实验功能标准建立独立管理页和受认证 API：状态、候选审核、词条详情、来源、反馈、手动研究和启停。
- 定时任务应具备单实例锁、超时、请求/Token 预算、失败退避与可观测状态；关闭时取消计时器和在途任务。
- 做到位后才开放灰度测试；未经真实模型/搜索适配器的集成测试，不要宣布自动学习已生效。
